手寫去背貼章工具

拍紙上手寫 → 自動去背 → 貼到 PDF／圖片 → 直接下載上傳．全程在你手機本機處理

1拍下手寫的紙

白紙黑筆、光線平均、盡量正對拍攝。一張紙可以同時寫簽名、日期、身分證字號，稍後再分開框選。

6匯出

PDF 會保留原本的文字與畫質，只把手寫疊上去。

手機下載後，通常在「檔案」App 的「下載項目」裡，直接從那裡上傳給公家機關即可。

怎麼用（第一次看這裡）

① 拿一張白紙，用黑筆把要簽的東西都寫上去：簽名、日期、身分證字號、電話…寫大一點、彼此隔開。
② 手機拍照 →「手寫素材」上傳 → 調到只剩筆跡 → 一塊一塊框起來存。
③ 到「貼到文件」開 PDF → 點素材 → 拖到欄位上 → 匯出下載 → 上傳。
④ 簽名記得按「存 PNG」下載，以後就不用再拍了。

去背調不乾淨怎麼辦？

還看得到灰灰的紙／陰影：把「去背強度」往右拉。
筆跡變斷斷續續、太細：把「去背強度」往左拉，或把「筆跡柔邊」往右拉。
只有某個角落髒髒的：那多半是陰影，把「陰影容忍度」往左拉（讓它用更小的範圍判斷）。
有一顆一顆小黑點：把「雜點清除」拉到 2～3。
最有效的一招：重拍。把紙放在光線平均的地方，不要讓自己的影子壓在紙上，手機正上方垂直拍。

Word 檔怎麼辦？

兩條路，選一條：
A（推薦）：Word 裡「另存新檔 → PDF」，再用本工具貼上、匯出 PDF 上傳。多數機關收 PDF。
B：在「手寫素材」按素材下面的「存 PNG」下載透明圖，回到 Word「插入 → 圖片」，把文繞圖設成「文字在前」或「浮於文字上方」，再拖到欄位上。

安全性：我的身分證字號會外流嗎？

不會。這個頁面沒有任何後端，也不會把檔案傳出去 —— 照片、PDF、手寫圖全部在你手機的瀏覽器記憶體裡處理，關掉分頁就清空。你可以開飛航模式測試：載入頁面後斷網，功能照樣運作。
但仍請注意：下載到手機的透明簽名 PNG 等同你的印章，別放在會自動同步分享的相簿或雲端資料夾。

法律上這樣算不算親簽？

本工具做的是「把你本人手寫的筆跡，用影像方式放到文件上」，和你自己列印簽名後掃描回傳，在影像結果上是一樣的。
但各機關規定不同：有些明確要求「正本親簽」或「浮水印／騎縫」，有些會要求同時檢附身分證影本。送件前建議先看該機關的須知，或打電話問一句「掃描電子檔的簽名可以嗎」，避免退件。這是提醒不是法律意見。

離線使用

本頁需要在第一次載入時取得 PDF 處理函式庫。若只處理「圖片文件」或只做「去背存 PNG」，完全不需要網路。要離線也能處理 PDF 的話，把這個 HTML 存到手機、並在有網路時先開一次讓瀏覽器快取即可。
