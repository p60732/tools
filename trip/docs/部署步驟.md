# 旅遊小筆記 v0.2：開啟全家同步（部署步驟）

> 大約 15 分鐘。需要你本人登入 Google、按授權視窗；AI 不能代按。
> 還沒完成這些步驟前，網頁照樣是「本機模式」，不影響使用。

## 1. 建立 Apps Script 專案
1. 打開 https://script.google.com → **新專案**，專案名稱改成「旅遊小筆記後端」。
2. 左邊「檔案」：把 `trip/gas/` 裡的 8 個 `.gs` 檔各建一個同名檔案，內容整份貼上（`00_config` 到 `90_admin`）。
3. 左邊齒輪「專案設定」→ 勾「在編輯器中顯示 appsscript.json」→ 把 `trip/gas/appsscript.json` 內容貼上。

## 2. 初始化（建立試算表、資料夾）
1. 上方函式選單選 **DANGER_setupTripNotebook** → 執行 → 跳出授權視窗時按「允許」（你本人操作）。
2. 打開下面「執行紀錄」，把印出來的四行 ID 貼到 `00_config.gs` 的 `CFG` 裡，存檔。也把它們抄到 repo 的 `trip/deploy.config.json`。
3. 確認雲端硬碟多了「旅遊小筆記」資料夾，裡面有「旅遊小筆記-正式」「旅遊小筆記-紀錄」「附件」「備份」。

## 3. 設定家庭密碼（只存雜湊）
1. 「專案設定」→ 最下面「指令碼屬性」→ 新增屬性 `NEW_PASSWORD`，值填家庭密碼（至少 6 個字）。
2. 回編輯器執行 **APPLY_NEW_PASSWORD**。執行紀錄會說「NEW_PASSWORD 已刪除」；回指令碼屬性確認真的不見了。

## 4. 部署成網頁應用程式
1. 右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**任何人**。（程式內有密碼驗證，這是唯一防線，所以密碼不要太簡單。）
3. 部署後複製 `/exec` 結尾的網址 → 貼到 `trip/deploy.config.json` 的 `GAS_EXEC_URL`，再告訴 Claude 把它填進 `index.html` 的 `API_URL`，推上 GitHub。
4. 驗證：用瀏覽器直接打開那個網址，應該看到 `{"success":false,"health":true,...}`（這是刻意的健康檢查頁）。

## 5. 每日備份
1. 執行 **installBackupTrigger** → 執行紀錄顯示「目前 dailyBackup 排程數：1」。
2. 左邊鬧鐘圖示「觸發條件」頁面，**確認真的有一筆 dailyBackup**（不要只看「執行完畢」）。
3. 想實測：暫時執行 **dailyBackup** 一次，到「備份」資料夾確認多了兩個副本。

## 6. 第一次使用
1. 手機打開 https://p60732.github.io/tools/trip/ ，重新整理一次拿到新版。
2. 輸入家庭密碼、選你是誰。
3. 你手機上 v0.1 存的行程會顯示「只在這支手機」→ 到「工具 → 我的旅程」按 **☁️ 上傳給全家**。
4. 家人用同一個網址、同一組密碼登入，就會自動打開最近的旅程。

## 之後
- **改程式**：貼上新的 `.gs` → 存檔 →「部署 → 管理部署作業 → 編輯 → 版本：新版本」。網址不變。
- **換密碼**：重做步驟 3（所有手機會被登出）。
- **手機遺失**：執行 **LOGOUT_EVERYONE**，所有手機都要重新登入。
- **資料出事**：先確認是不是指到別的試算表（CFG 的 ID），再從「備份」資料夾拿副本，**不要重新初始化**。
- **回到上一版**：「部署 → 管理部署作業」選前一個版本。
