## 每一列的欄位（每張表都一樣）

`tripId | key | data(JSON) | rev(版本) | seq(全域流水號) | updatedBy | updatedAt | deleted`

- 改資料一律「改那一列」或「新增一列」，不整張重寫。
- 刪除只標 `deleted=TRUE`（附件會把雲端硬碟檔案丟垃圾桶）。
- 送出修改時帶上次看到的 `rev`；跟現在不同代表別人先改了 → 回傳衝突，由使用者選「用他的／用我的」。

## 讀寫怎麼切（效能）

- Script Properties `SEQ` = 全域最新流水號；`CSEQ` = 每張表最後變動的流水號（`{"stop":123,...}`）。
- 輪詢 `pull since=N`：`N ≥ SEQ` 直接回空的（不開試算表）；否則只讀 `CSEQ` 比 N 新的那幾張表。
- 寫入 `push`：上鎖 → 每張表讀一次 → 新增的列排隊、最後一次 `setValues` 寫進去 → `SEQ`／`CSEQ` 一次寫回。
- 每次請求只整包讀一次 Script Properties。
- 效能估算：`node tests/perf.js`（數慢的 Google 服務呼叫次數）。
