# tools

個人小工具箱。每個工具都是單一 HTML，純前端、無後端，檔案不會離開使用者的裝置。

- `sign.html` 手寫去背貼章工具：拍下紙上的手寫 → 自動去背 → 貼到 PDF／圖片 → 下載上傳
- `kids-games/` 幼兒遊戲大全：收玩具、火車站長、消防隊、形狀配對、大小配對、ABC 大小寫、ㄅㄆㄇ 注音、鐵路接接看、蒙特梭利玩具櫃、密碼解鎖、挖寶沙坑（海邊、化石、菜園、雪地；平板、手機可直接玩；加入主畫面後可離線使用）
- `trip/` 旅遊小筆記：日系繪本風行程網站，每日行程（拖曳排序、備案、預約狀態）、航班接送、住宿、票券夾、行李清單、匯率小算盤；可加入主畫面離線使用。v0.1 資料只存在本機，全家同步待下一版
